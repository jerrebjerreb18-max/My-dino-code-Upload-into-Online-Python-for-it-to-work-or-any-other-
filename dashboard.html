SUPPORT
Help center
How the dashboard panels work and what is needed to connect them.

        
Why is the player list empty?
The website is static right now. It needs a backend route that reads the ER:LC API through your bot and returns player data.
Where does the server key go?
Keep it in the bot host's environment variables. Never paste it into this website, the browser, or GitHub.
How do roles protect commands?
The backend must authenticate the Discord user and check their current server roles before it executes every command.
Why are moderation buttons disabled?
They stay disabled until a secure backend is connected. Ban and kick actions should always require a target, reason, and staff authorization.
How do I add a new panel?
Add a navigation button with a matching panel ID in dashboard.html, then add its behavior in dashboard.js.
Where do site changes go?
Commit changes to the main branch of the GitHub repository. GitHub Actions publishes the updated site.
